Project Case Study

Commission Reputation Platform

A trust and reputation web platform for artists and commissioners. The product helps people make safer commission decisions by collecting verified experience signals, structured reviews, and moderated fraud reporting.

Purpose

Commission spaces often rely on scattered social proof and private warning lists. This platform centralizes reputation signals into one transparent destination where community reporting is allowed, but deletion and enforcement stay moderator-controlled to reduce abuse.

How It Was Built

  • Designed database models for profiles, dual-role reviews, scam reports, and moderation decisions.
  • Implemented role-aware submission flows so users can review as artist, commissioner, or both.
  • Added soft-delete moderation for review reports flagged as unserious or fabricated.
  • Integrated sign-in using X OAuth with server-side session handling.
  • Deployed to Vercel with Neon PostgreSQL and Prisma schema sync during builds.

Technical Stack

  • Frontend: Next.js App Router + TypeScript
  • Backend: API routes in Next.js server runtime
  • Database: Prisma ORM + PostgreSQL
  • Authentication: NextAuth with Twitter/X provider
  • Validation and scoring: zod + custom ranking logic
