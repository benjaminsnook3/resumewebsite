SeattlePulse

A Seattle-focused app that turns weather, transit, sports, events, and traffic data into one useful picture of the city. Instead of making people interpret five separate feeds, SeattlePulse calculates transportation impact and surfaces the information most likely to affect their plans.

What It Solves

Seattle conditions are shaped by several systems at once. A rainy commute, a Link disruption, and a game near the stadiums can each matter on their own, but the useful answer is how they combine. SeattlePulse normalizes those signals and explains the resulting level of transportation pressure with human-readable factors.

How It Was Built

  • Built a Spring Boot Kotlin backend with REST endpoints for weather, transit, sports, events, traffic, alerts, and dashboard data.
  • Normalized provider records into canonical models and stored them with Spring Data JPA.
  • Created an impact engine that weighs disruptions and nearby events across four capped categories.
  • Added location-aware neighborhood views without requiring location permission in the backend.
  • Connected the API to an Android Compose app using Retrofit, with notification policies to prevent alert spam.

Technical Stack

  • Backend: Kotlin + Spring Boot
  • Persistence: H2 + Spring Data JPA
  • Android: Jetpack Compose + Material 3
  • Networking: Retrofit + OkHttp
  • Providers: Open-Meteo, Sound Transit, King County Metro, ESPN, Ticketmaster
